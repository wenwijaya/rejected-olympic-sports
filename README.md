One funny single-line sport the Olympics rejected: a made-up event, real enough to sound like a broadcast, absurd enough to be funny, and short enough to fit in 200 characters. This program writes that one line to `/output/entry.txt` — competitive napping, where athletes race to fall asleep on live TV while the commentators whisper, and the first to snore is disqualified.

## Run it

```sh
node main.ts
```
